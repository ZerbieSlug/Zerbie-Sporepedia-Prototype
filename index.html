Introduction

Hello!
This is a proof-of-concept (prototype) of a website that I'd like to make for a collab.
It does look rough on a lot of things (and DON'T check the code in the sporpedia/cards.html),
but this is to test if the idea of hosting submissions in this style is feasible.

Right now, the main focus of this "website" is to test the functionality found within the "Sporepedia" tab.
So if you look to your left, click on that link to see the thing I worked 2 whole days on.
If you're one of the people who are part of this collab I'm in, feel free to provide me feedback before
I transform this into something else for the collab's subject.

Implemented Features

  • Basic Page System
  • Hiding buttons when first loading the page
  • Grid-based card selection menu
  • A selected card that changes based on what's picked
  • Name/Descriptions that update based on what's picked
  • A working series of tabs that change what cards can be chosen/shown on screen
  • Tab Buttons that change when clicked
  • Hiding card options if total entries per category are not fully divisible by 9
  • Music Player
  • Simple animation when picking a card
  • Selection "icon" cards are overlayed over a shared background

Known Problems

  • This website only works for PC users, I haven't made it compatible for mobile devices.
  • Loading is a little slow... I can't fix that sorry!

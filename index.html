Introduction

Hello!
This is a proof-of-concept (prototype) of a website that I'd like to make for a collab.
It does look rough on a lot of things (and DON'T check the code in the sporpedia/cards.html),
but this is to test if the idea of hosting submissions in this style is feasible.

As of 8/19/2026, this prototype has hit what I believe to be its final iteration.
Some time after this prototype's changes all finish applying, I will be getting to work into converting this SPORE-themed project into a project themed around ANOTHER game...
It's likely I'll still have to rework some more systems for the legitimate website, but otherwise I've achieved the vision I have for this site's main gimmick.
Can't wait to show you what this is leading up to!

Implemented Features

  • Basic Page System
  • Hiding buttons when first loading the page
  • Grid-based card selection menu
  • A selected card that changes based on what's picked
  • Name/Descriptions that update based on what's picked
  • A working series of tabs that change what cards can be chosen/shown on screen
  • Tab Buttons that change when clicked
  • Music Player
  • Selection "icon" cards are overlayed over a shared background
  • Tested out functionality for a 3x2 grid in case the total amount of entries aren't divisible by 9
  • Should now work with a majority of mobile devices!
